状态：占位。工程尚未初始化，本目录暂无代码。

职责

唯一的数据持有者与业务逻辑实现者。对外提供 HTTP JSON 接口，供管理端 Web 与大屏调用。

技术基线

项 选型 依据
JDK Java 25（LTS），显式锁定 ADR-0004
框架 Spring Boot 4.1.x 同上
构建 Maven 同上
数据库 / 持久层 / 缓存 / 鉴权实现 未定 架构阶段决策

初始化前置条件

# 事项 说明
1 安装 JDK 25 本机当前只有 JDK 27，Java 25 未安装（实测）
2 设置 JAVA_HOME 当前为空；否则 Maven 会挑到 JDK 27，产生版本漂移
3 功能设计与架构设计定稿 见 docs/02-functional-design/、docs/03-architecture/

详见 docs/00-meta/dev-environment.md。

backend/
├── pom.xml
├── src/main/java/...        # 分层：接口层 / 应用层 / 领域层 / 基础设施层（具体分层待架构定）

│   ├── application.yml

硬性约束（来自 ADR-0002 / ADR-0003）

  1. 所有业务数据必须有租户归属，所有查询必须携带租户上下文。
  2. 授权必须后端独立校验，不得依赖前端隐藏。
  3. 认证与加密不得自研。
  4. 必须存在自动化跨租户越权测试。
  5. 密钥不得提交仓库。
