04 功能需求池 Functional Requirements

编号规则：FR-D{域号}-{序号}；跨域能力用 FR-G-{序号}。 优先级：P0 v1 必做 / P1 v1.1~v2 / P2 远期。 "验收要点"列只写可判定的判据，不写主观描述。详细用例留到功能设计阶段。

需求条目数量参考：P0 = 主线交付；P1 = 主线跑通后的增强；P2 = 需求池，不排期。

一、跨域通用能力 FR-G

ID 需求 优先级 验收要点
FR-G-01 附件上传与关联 P0 任意业务对象可挂附件；单文件 ≤20MB；支持 pdf/jpg/png/heic
FR-G-02 富文本备注 P1 备注支持纯文本 + 换行；不支持 HTML 注入
FR-G-03 标签体系 P1 可给记录打自定义标签，可按标签筛选
FR-G-04 全局搜索 P1 输入关键词可跨域检索，结果按域分组；不检索他人不可见数据
FR-G-05 通用列表能力 P0 所有列表支持：分页、排序、按时间/成员筛选、导出当前筛选结果
FR-G-06 批量录入 P0 支持 Excel/CSV 模板导入；导入前提供预览与错误行报告
FR-G-07 时间序列展示 P0 数值型记录可按时间轴绘制趋势；缺失点不插值
FR-G-08 变更审计 P0 敏感域的增删改留痕（谁、何时、改了什么）
FR-G-09 回收站 P1 删除进回收站，≥30 天可恢复；超期自动清除
FR-G-10 统一提醒引擎 P0 所有"到期类"需求只调用此引擎，不各自实现

二、D01 家庭与成员

ID 需求 优先级 验收要点
FR-D01-01 创建家庭 P0 注册后自动成为家庭管理员；家庭有唯一标识
FR-D01-02 管理员新增/编辑/停用成员 P0 可创建无账号成员；停用后其数据保留
FR-D01-03 邀请成员加入 P0 生成邀请码/链接，有有效期；接受后绑定为家庭成员
FR-D01-04 成员基础档案维护 P0 姓名/称谓/性别/生日（含农历）/头像；姓名与生日必填
FR-D01-05 成员可变属性维护 P1 尺码/血型/过敏源等，支持历史值
FR-D01-06 家庭关系与同住标记 P0 每个成员标记与管理员关系、是否同住
FR-D01-07 角色分配 P0 管理员可为成员指定内置角色或自定义角色
FR-D01-08 管理员变更（移交） P1 可指定另一成员为管理员；原管理员降级，不丢数据
FR-D01-09 证件档案 P1 证件号加密存储；到期日推送提醒；查看需二次确认
FR-D01-10 紧急联系人 P1 每个成员可设≥1 名紧急联系人

三、D02 工作与职业

ID 需求 优先级 验收要点
FR-D02-01 任职信息维护 P0 单位/职位/入职日期；支持多段任职历史
FR-D02-02 薪酬结构记录 P0 记录构成项与发薪日；默认仅本人+管理员可见
FR-D02-03 社保公积金记录 P1 缴纳基数/比例/城市；与 D04 账户不重复录入
FR-D02-04 假勤额度 P1 年假总额/已用/剩余可维护；剩余量可被提醒
FR-D02-05 证书与技能 P1 证书含有效期；到期推送提醒
FR-D02-06 工作日程（排班/出差） P1 可在家庭日历中体现可见部分

四、D03 健康与医疗

ID 需求 优先级 验收要点
FR-D03-01 指标字典（含自定义） P0 内置常用指标；家庭可新增自定义指标（名称/单位/参考区间）
FR-D03-02 指标记录录入 P0 记录值+时间；超出参考区间有视觉标记
FR-D03-03 指标趋势图 P0 单指标多时间点折线；支持选时间段
FR-D03-04 体检记录 P0 机构/日期/结论 + 报告附件；可标记异常项
FR-D03-05 体检异常项跟进 P1 异常项可转为待办并跟踪复查
FR-D03-06 用药记录 P0 药品/剂量/频次/起止；可设提醒时间
FR-D03-07 用药提醒与服药打卡 P1 到点提醒；可标记"已服/漏服"
FR-D03-08 疫苗记录 P1 疫苗/剂次/日期；可设下次时间提醒
FR-D03-09 过敏与病史 P0 过敏源/既往史/手术史/家族史；在成员详情页显著展示
FR-D03-10 就诊记录 P0 医院/科室/诊断/费用 + 单据附件
FR-D03-11 医疗费用与报销 P1 记录总额/医保/自付；汇总至 D04
FR-D03-12 儿童成长曲线 P1 身高/体重/头围按月龄绘制
FR-D03-13 运动与睡眠记录 P2 手工录入；预留外部设备同步扩展点
FR-D03-14 女性健康 P2 经期/孕期记录
FR-D03-15 禁止诊疗建议 P0 系统任何位置不得输出诊断、用药建议；仅展示客观数据与参考区间

五、D04 财务与资产

ID 需求 优先级 验收要点
FR-D04-01 账户管理 P0 账户类型/名称/机构；支持标记"共享账户"
FR-D04-02 收支记账 P0 3 次点击内完成一笔；支持成员归属与账户归属
FR-D04-03 收支分类 P0 内置一套分类，可自定义增删改；支持二级分类
FR-D04-04 流水查询与统计 P0 按月/成员/分类筛选并汇总；支持导出
FR-D04-05 批量导入流水 P0 Excel/CSV 导入，导入前预览去重
FR-D04-06 预算与超支预警 P1 按月设总预算与分项预算；达阈值推送提醒
FR-D04-07 资产负债快照 P1 按月记录总资产/负债/净值并看趋势
FR-D04-08 负债与月供管理 P0 贷款本金/利率/剩余期数/还款日；还款日推送提醒
FR-D04-09 账单与订阅管理 P0 固定扣费项与订阅；到期前提醒；可一键标记已付
FR-D04-10 保险保单管理 P1 保单关键字段 + 保单附件；缴费日提醒
FR-D04-11 投资持仓记录 P2 仅记录成本与份额，不接行情、不做建议
FR-D04-12 财务目标 P2 目标金额与进度展示
FR-D04-13 账户级可见性 P0 可设置某账户对指定成员完全不可见

六、D05 房产与车辆

ID 需求 优先级 验收要点
FR-D05-01 房产档案 P1 地址/面积/产权人/购入信息 + 产权证附件
FR-D05-02 房产贷款与出租 P1 关联 D04 负债；租客与租期管理
FR-D05-03 车辆档案 P1 车牌/型号/VIN/里程
FR-D05-04 车辆到期提醒 P1 保险、年检、保养三类到期日提醒
FR-D05-05 车辆维保记录 P1 保养/维修历史，含费用

七、D06 家居与设备

ID 需求 优先级 验收要点
FR-D06-01 家电设备档案 P1 型号/购入日期/价格 + 发票说明书附件
FR-D06-02 保修到期提醒 P1 保修期到期前提醒
FR-D06-03 维修记录 P1 设备维保历史
FR-D06-04 家庭药箱库存 P1 药品/数量/有效期；临期提醒；用药时自动扣减
FR-D06-05 日用品库存 P2 最低库存阈值触发补货提醒
FR-D06-06 固定费用户号管理 P1 水电燃气/宽带/物业户号与缴费周期；关联 D04

八、D07 日历与日程

ID 需求 优先级 验收要点
FR-D07-01 家庭共享日历 P0 创建事件、指定参与成员；成员可在同一视图中看到
FR-D07-02 个人日程 P0 可设为仅本人可见
FR-D07-03 纪念日与生日 P0 支持公历/农历；支持年重复；支持"提前 N 天提醒"
FR-D07-04 待办事项 P0 负责人/截止日/优先级/状态；可指派给其他成员
FR-D07-05 重复任务规则 P1 支持每天/每周/每月/自定义重复
FR-D07-06 家务分工与轮值 P1 定义轮值规则、自动排班、完成打卡
FR-D07-07 统一提醒中心 P0 聚合全部域的到期项；统一设置提前量与渠道；可标记已处理
FR-D07-08 日历视图 P0 月视图 + 周视图 + 议程列表；移动端可读
FR-D07-09 iCal 订阅导出 P1 可导出只读日历订阅地址
FR-D07-10 家庭会议记录 P2 议题/决议/跟进项

九、D08 子女与教育

ID 需求 优先级 验收要点
FR-D08-01 学校与班级信息 P1 学校/年级/班级/班主任联系方式
FR-D08-02 课表 P1 周课表可维护，可在日历视图中展示
FR-D08-03 成绩记录 P1 考试/科目/分数/满分；可选记录排名
FR-D08-04 课时余额管理 P1 记录总课时、每次消课、剩余自动计算并提醒
FR-D08-05 成长记录 P1 复用 D03 成长曲线；支持里程碑与照片
FR-D08-06 素质档案 P2 获奖/考级证书 + 附件

十、D09 长辈照护

ID 需求 优先级 验收要点
FR-D09-01 照护档案 P1 行动能力/认知状态/护理等级
FR-D09-02 照护排班 P1 陪护值班表；可提醒当班人
FR-D09-03 极简打卡 P1 单按钮完成服药/体征打卡；长辈可独立操作
FR-D09-04 医疗资源档案 P1 常去医院/主治医生/医保信息
FR-D09-05 养老规划 P2 养老资金与机构意向记录

十一、D10 关系与人情

ID 需求 优先级 验收要点
FR-D10-01 亲友通讯录 P1 姓名/关系/生日（含农历）；生日进提醒中心
FR-D10-02 亲属关系图谱 P1 可表达父系/母系分支与称谓
FR-D10-03 人情往来账 P1 记录收/送礼（对象/事由/金额/日期）；可按对象汇总
FR-D10-04 还礼提示 P1 同一对象再次有事时，提示历史上往来记录
FR-D10-05 社交分组 P2 同事/同学/亲戚等分组

十二、D11 生活事务与行政

ID 需求 优先级 验收要点
FR-D11-01 证件到期统一管理 P0 汇总全部证件到期日；支持提前量配置；进提醒中心
FR-D11-02 会员订阅管理 P1 与 D04 订阅统一，不重复录入
FR-D11-03 宠物档案 P2 品种/疫苗/驱虫/就诊
FR-D11-04 签证与出入境 P2 签证有效期与出入境记录
FR-D11-05 家庭日记 P2 图文记录，可在大屏展示

十三、D12 旅行与出行（整体 P2）

ID 需求 优先级 验收要点
FR-D12-01 行程计划 P2 目的地/日期/参与人/预算
FR-D12-02 订单管理 P2 交通与住宿订单关键信息
FR-D12-03 行李清单模板 P2 可按目的地/季节套用模板

十四、D13 文档与知识库

ID 需求 优先级 验收要点
FR-D13-01 家庭文件库 P0 按类型/标签/归属组织；支持预览与下载
FR-D13-02 附件与业务对象关联 P0 从各域详情页可直接上传并回看
FR-D13-03 文件检索 P1 按文件名/标签/上传时间检索
FR-D13-04 应急手册 P1 集中展示急救信息、常去医院、紧急联系人
FR-D13-05 重要信息保管 P1 强加密 + 访问审计；若无法保证安全则 v1 不做（见 Q-010）
FR-D13-06 家谱与纪念 P2 家族故事与老照片长期沉淀

十五、D14 大屏与展示

详细需求见 06-dashboard-requirements.md。

ID 需求 优先级 验收要点
FR-D14-01 大屏设备注册与配对 P0 通过一次性配对码授权，无需输入账号密码
FR-D14-02 可拖拽布局编辑 P0 增删/拖拽/缩放卡片；保存后大屏实时生效
FR-D14-03 多布局保存 P0 一个家庭可保存多套布局并切换
FR-D14-04 卡片库 P0 提供 ≥10 种预置卡片
FR-D14-05 敏感卡片脱敏 P0 财务/健康卡片默认隐藏或模糊；可按场景切换
FR-D14-06 自动刷新 P0 数据按配置周期自动刷新，失败不白屏
FR-D14-07 防烧屏 P0 支持像素偏移/定时微移，长时间静态元素不残留
FR-D14-08 夜间模式 P1 按时间段自动调暗或熄屏
FR-D14-09 场景切换 P1 布局+主题+脱敏级别的组合切换
FR-D14-10 加载态与错误态 P0 单卡片失败只影响该卡片，其它卡片正常展示

十六、D15 平台与系统

详细需求见 05-identity-and-tenancy.md。 本节仅列条目，验收要点在该文档展开。

ID 需求 优先级
FR-D15-01 家庭（租户）注册与创建 P0
FR-D15-02 账号注册 / 登录 / 登出 P0
FR-D15-03 密码策略与找回 P0
FR-D15-04 二次验证 P1
FR-D15-05 第三方登录（微信等） P1
FR-D15-06 角色与权限点管理 P0
FR-D15-07 成员间可见性规则配置 P0
FR-D15-08 租户数据隔离 P0
FR-D15-09 通知中心（站内） P0
FR-D15-10 外部通知渠道（短信/邮件/微信） P1
FR-D15-11 通知偏好设置 P1
FR-D15-12 审计日志 P0
FR-D15-13 数据导入（Excel/CSV） P0
FR-D15-14 全量数据导出 P0
FR-D15-15 家庭注销与数据删除 P0
FR-D15-16 备份与恢复 P0
FR-D15-17 平台运营后台 P1
FR-D15-18 帮助与新手引导 P1
FR-D15-19 开放接口 / 集成扩展点 P2

十七、需求统计

优先级 条目数（含 05/06 引用项）
P0 约 55
P1 约 50
P2 约 20

P0 数量偏多是当前最大风险。v1 实际应再砍 30% 左右，取舍方法见 08-scope-and-phasing.md。
