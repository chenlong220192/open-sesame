本次调研的核心结论（速读）

  1. 信息域比你最初想的多：你提到 3 项（人员基础、工作、健康），扩展后是 15 域 / 107 子域。其中我认为最不该漏的是 ——
    • D04 财务与资产：家庭最刚性的信息，且与工作、房贷车贷、教育支出强关联
    • D11 证件/账单到期管理：数据量极小但价值极高（一次提醒可能省掉巨大麻烦）
    • D10 人情往来（还礼提醒）：中国特色刚需，成本低、体验强
    • D13 文档与知识库：不是可选功能，是所有域的附件基础设施
  2. "多租户 SaaS"把用户管理从功能升级为底座：租户隔离、权限点、成员间可见性必须在 v1 就做对，后补成本是数量级的（ADR-0002）。成员间可见性默认值（Q-005）是我认为最需要你尽早拍板的一条。
  3. 大屏是最大技术风险，且风险前置在"电视能不能跑"而不是"前端怎么写"（Q-004）。建议进架构阶段第一件事就是实测目标电视。
  4. v1 范围必须砍：P0 约 55 条对"单人 + 业余时间"明显过载。08 给出了可执行的砍法，并建议大屏 v1 只做 4 张卡。
  5. 安全要求因"公有云"而不可妥协：07 中 NFR-SEC-01~14 是硬性要求；且已记录 5 类"技术债不可接受项"。
