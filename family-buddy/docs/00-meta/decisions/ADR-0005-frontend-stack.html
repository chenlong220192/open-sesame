ADR-0005 前端技术栈：Vue 3

源文件docs/00-meta/decisions/ADR-0005-frontend-stack.md 项目family-buddy 阶段调研 · 需求分析
本页目录
  • 背景
  • 决策
  • 备选方案与取舍
  • 版本现状核实（2026-10-01 查证）
  • 后果
  • 状态：已接受
  • 日期：2026-10-01
  • 决策者：项目所有者
  • 影响范围：前端全部代码、构建、UI 组件选型

背景

所有者指定前端使用 Vue 3。项目前端有两个形态，需求差异很大：

形态 使用者 交互 尺寸
管理端 Web 家庭成员（电脑/手机浏览器） 强交互、频繁录入 响应式
大屏 Dashboard 电视（遥控/弱交互） 只读展示、自动刷新、常驻 固定 16:9

决策

整体基于 Vue 3 + Vite + TypeScript。

两个形态的工程关系，本 ADR 不决策 —— 这是一个需要真实权衡的架构问题（同工程多入口 vs 独立工程），留到架构阶段，届时需新增 ADR。本 ADR 仅锁定"语言与框架层"。

备选方案与取舍

方案 优点 缺点 采纳
Vue 3 所有者指定；Composition API 适合复杂状态；大屏与后台生态都成熟；上手快 — ✅
React 生态最大 所有者未选；无必要引入 ❌
Vue 2 — 已于 2023-12-31 EOL，不再有安全补丁 ❌ 明确排除

版本现状核实（2026-10-01 查证）

事实 来源级别
Vue 3.5.x 为当前主线小版本 文档（多方一致）
Vue 2 已于 2023-12-31 EOL 文档（官方公告，多方一致）
Vite 7.x 为当前主流构建版本 文档（2026 年技术栈汇总，非官方一手）
Pinia 3.x / Element Plus 2.14.x 为当前主流 文档（同上，非官方一手）
Vue Router 版本存在冲突信息：多数来源称 4.x，亦有来源称 5.1.0 未验证 —— 存在矛盾，工程初始化时以 npm view vue-router version 实测为准
Vue Vapor 模式仍处 RFC 阶段，不影响当前选型 文档（社区回顾文章，非官方一手）

说明：上表中标注"非官方一手"的版本号仅作趋势参考，不得作为 package.json 的写入依据。工程初始化时全部实测确定。

后果

  • 正面：框架层确定，可直接进入需求与功能设计。
  • 需注意：
    • 大屏电视端浏览器可能是老旧内核（Android TV / 智能电视自带浏览器）。若采用较新的 ES 特性，需要构建期降级。该风险在架构阶段必须实测目标电视的浏览器内核版本后再定，不能靠推测。
    • 组件库、状态管理、CSS 方案、是否使用 Nuxt —— 全部留待架构阶段决策。
  • 未决项：管理端与大屏是否同工程、组件库选型、是否 SSR。
