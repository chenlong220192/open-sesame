〇、运行环境变更（2026-10-03，实测）

项 变更前 变更后
工作区位置 虚拟机共享卷 <工作区根>/ 宿主机本地磁盘 <工作区根>/
访问方式 虚拟机内经共享卷访问宿主机文件 本机直接访问，无跨宿主机的中间层
共享卷挂载 mount 中可见 已不再挂载（mount | grep -i "shared files" 为空）

判定物理机而非虚拟机的可靠依据：pmset -g batt 出现 InternalBattery（macOS 不模拟电池）。 本机实测 InternalBattery-0 … 71%; charging → 物理机。 （宿主机上确实运行着 VMware Fusion.app，但那只能说明宿主上开着 VMware，与本机身份无关 —— 不能用进程列表判断自身是不是虚拟机。）

对工具链的影响：

  1. 跨卷的删除限制已消失。实测宿主机本地磁盘上 rm <文件> 成功； rmdir <空目录> 仍被拦截（Operation not permitted）。 → 结论从「本卷一律禁止删除」收窄为「目录删除仍受限，文件删除可用」。 .tmp/ 废纸篓机制继续保留（目录搬移是整目录 mv，比逐个 rm 更稳）。
  2. 旧路径（/Volumes/...、<用户主目录>/...）在 publish.py 的脱敏规则中保留为防御性条目， 防止历史文档里残留旧路径时泄漏到公开仓。

二、后端工具链

项 状态 证据（实测） 探测日期
Maven ✅ 3.10.0，/opt/homebrew/Cellar/maven/3.10.0 mvn -v 10-03
Java 运行时（Maven 实际使用） ⚠️ JDK 27 mvn -v → Java version: 27 10-03
JDK 25（本项目目标） ❌ 未安装 /opt/homebrew/Cellar/ 下仅 openjdk(27) 与 openjdk@21；brew info openjdk@25 → 可安装但未装 10-03
JAVA_HOME ❌ 空 echo $JAVA_HOME 10-03
java / javac ⚠️ 需用完整路径；/opt/homebrew/bin/java 不存在（Homebrew 未link） 直接调/opt/homebrew/Cellar/openjdk/*/bin/java -version 才可用 10-03
Gradle 未安装 which gradle 无结果 10-03

结论（未变）：目标栈 Java 25 尚未就绪，Maven 会自动挑到 JDK 27，与「锁定 Java 25」不一致。 需 brew install openjdk@25 并把 JAVA_HOME 指向它。注意 Homebrew 的 openjdk 是 keg-only， 不 link 到 /opt/homebrew/bin，因此 java 命令不可直接用，必须靠 JAVA_HOME + PATH 或完整路径调用。

三、前端工具链

项 状态 证据（实测） 探测日期
Node（WorkBuddy managed） ✅ v22.22.2 node -v 10-03
npm（WorkBuddy managed） ✅ 已修复，10.9.7 可用 npm -v 10-03
Node（nvm） ✅ v24.20.0，npm 11.19.0 ls ~/.nvm/versions/node/ 10-03

旧结论已失效：10-01 记录的「bin/npm 包装脚本指向不存在的 ../lib/cli.js」在宿主机上 不复存在 —— 现在 bin/npm 是指向 ../lib/node_modules/npm/bin/npm-cli.js 的符号链接， npm -v 正常返回 10.9.7。managed 运行时被重建后该问题自愈，不必再「修」。 现在有两条 Node 可用（managed 22.22.2 / nvm 24.20.0），前端初始化时需明确选哪一条。

五、进入开发前的环境待办

# 事项 命令 阻塞级别 状态

E2 安装 JDK 25 brew install openjdk@25 阻塞：后端无法按目标版本构建 ❌ 待办
E3 设置 JAVA_HOME 指向 JDK 25 写入 ~/.zshenv（WorkBuddy 工具环境用 zsh -f，不读 .zshrc） 阻塞：同上 ❌ 待办
E4 前端 Node 选型（managed 22 / nvm 24 选一条） — 阻塞：前端工程初始化 ❌ 待办（原「修 npm」一条已作废）
E5 （可选）gh auth login — 非阻塞 ❌ 待办
E6 确认 Docker 可用性 本机已确认未安装 架构阶段前 ⚠️ 需决定是否装

E2/E3 涉及本机全局配置（~/.zshenv、brew）。是否现在处理，等你确认后再动手 —— 本页只做记录，未做任何修改。
