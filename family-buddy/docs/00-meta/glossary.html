全项目口径唯一来源。任何文档中出现的下列术语，含义以本表为准。 新增术语必须回写本表，避免同名不同义。

一、平台与租户

术语 英文 定义
平台 Platform family-buddy 系统本身，由运营方（我们）运维，承载所有家庭
租户 Tenant 一个家庭即一个租户。租户是数据隔离的最小单位
家庭 Household / Family 用户视角的名词，等价于租户。文档中两者同义
家庭空间 Family Space 一个家庭的全部数据集合的统称
家庭管理员 Household Admin 租户内的最高权限角色，可管理成员、角色与家庭级配置
成员 Member 隶属于某个家庭的账号持有者或被管理对象
成员档案 Member Profile 成员的结构化信息集合（基础信息 + 各域扩展信息）
非登录成员 Non-login Member 无账号的成员（如幼儿、不便操作的老人），仅作为被管理对象存在
平台运营 Platform Operator 平台的运维/客服角色，默认不可读租户业务数据

二、账号与权限

术语 英文 定义
账号 Account 一个可登录的身份。账号与成员的关系：一个账号在同一家庭内对应一个成员
角色 Role 家庭内的一组权限点的集合。允许家庭管理员自定义，内置三类模板
权限点 Permission 最小授权单位，形如 health:record:read
数据可见性 Visibility 成员间隐私控制：某成员在某信息域的数据对谁可见
大屏设备 Dashboard Device 电视端等常驻展示设备，通过设备授权而非账号密码接入
设备配对码 Pairing Code 大屏首次接入时的一次性授权码

三、信息域

术语 英文 定义
信息域 Information Domain 家庭信息的顶层分类，本项目管理 15 个域（D01~D15）
子域 Sub-domain 信息域下的二级分类，可理解为"一张表 / 一个功能集合"
指标 Metric 带单位与参考区间的可量化记录项（如血压、身高）
指标序列 Metric Series 同一指标在时间轴上的连续记录，用于趋势展示
档案 Record / Archive 结构化的历史记录（如就诊记录、体检记录）
单据 Document / Receipt 以文件形态存在的凭证（发票、扫描件、报告 PDF）

四、大屏

术语 英文 定义
大屏 Dashboard / 家庭看板 在电视等大屏幕上常驻展示的定制化信息面板
卡片 Card / Widget 大屏上的独立信息单元，可增删、拖拽、缩放
布局 Layout 一组卡片的排布方案。一个家庭可保存多套布局
场景 Scene 布局 + 主题 + 数据范围的组合，如"日常/节日/来客"
免登录展示 Kiosk View 大屏默认以只读、脱敏方式展示，不暴露敏感数据

五、工程

术语 英文 定义
单仓库多项目 Monorepo 一个 Git 仓库内含多个可独立构建的子项目
需求池 Backlog 未分配版本的全部需求条目集合
准出条件 Exit Criteria 某阶段可宣告完成的硬性检查项

六、待补充

以下术语在后续阶段出现时需补入本表：
