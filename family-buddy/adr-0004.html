ADR-0004 后端技术栈：Java 25 + Spring Boot 4

本页目录

  • 版本现状核实（2026-10-01 查证）
  • 决策
  • 理由
  • 需要接受的成本与风险
  • 未决项（架构阶段）
  • 状态：已接受
  • 日期：2026-10-01
  • 决策者：项目所有者
  • 影响范围：后端全部代码、构建、CI、部署基线

背景

所有者指定后端使用 Java 25 + Spring Boot 4。需确认该组合的可行性、版本现状与迁移风险。

版本现状核实（2026-10-01 查证）

事实 来源级别
Spring Boot 4.0.0 于 2025-11-20 正式 GA，基于 Spring Framework 7 文档（spring.io 官方博客）
Spring Boot 4.1.0 于 2026-06-10 GA，为 4.x 首个次版本 文档（spring.io 官方博客）
Spring Boot 4.0 要求 Java 17 起，并一等公民支持 Java 25 文档（spring.io 官方博客 / 官方系统需求页）
Spring Boot 4.1 支持 Java 17–26（jOOQ 3.20 需 Java 21） 文档（HeroDevs 汇总，非官方一手）
Spring Boot 4.2 预计 2026-11 发布 文档（InfoQ，非官方一手）
Spring Boot 4 基于 Jakarta EE 11（Servlet 6.1 / JPA 3.2 / Validation 3.1） 文档（官方迁移指南）
Spring Boot 4 默认 JSON 库改为 Jackson 3，Jackson 2 被移除 文档（官方迁移指南 / InfoQ）
Spring Boot 4 移除 Undertow；移除 JUnit 4；移除 3.x 全部弃用 API 文档（官方迁移指南）
Spring Boot 4 模块化拆分：starter 命名统一为 spring-boot-starter-*，原先"无 starter"的第三方（如 Flyway/Liquibase）现在必须用 spring-boot-starter-flyway 等 文档（官方迁移指南）

决策

采用 Java 25（LTS）+ Spring Boot 4.1.x + Maven。

  • pom.xml 中显式锁 java.version = 25，不用 latest。
  • 依赖基线取 Spring Boot 4.1.x 最新补丁（具体补丁号在工程初始化时以 Maven Central 实际版本为准，本文不预设）。

理由

  1. Java 25 是 LTS，Spring Boot 4 对其"一等公民支持"，组合处于官方支持矩阵内。
  2. Spring Boot 4.1 是新项目官方推荐基线；4.0.x 的 OSS 支持窗口预计 2026-12-31 结束，新项目直接起 4.1 可避免半年内就要升级。
  3. 从零开始，不存在 3.x → 4.x 的迁移包袱（Jackson 3、Undertow 移除、弃用 API 移除等破坏性变更对本项目无成本）。

需要接受的成本与风险

风险 说明 应对
生态滞后 Spring Boot 4 发布于 2025-11，相比 3.x 生态，部分第三方库（连接池、监控、国产中间件 SDK）可能尚未适配 Jackson 3 / Jakarta EE 11 架构阶段选型时逐个确认；优先选有 spring-boot-starter-* 官方支持的组件
中文资料少 4.x 的中文实践文档明显少于 3.x 以官方文档为准；遇到问题优先查 GitHub issues
JDK 25 本地未装 本机目前只有 JDK 27，Java 25 未安装（实测） 见 00-meta/dev-environment.md E2/E3
JDK 版本漂移 本机 Maven 当前自动使用 JDK 27（实测），与目标 25 不一致 显式设置 JAVA_HOME；后续在 CI 与 pom.xml 双重锁定
-DskipTests 行为变更 4.1 起 Maven 插件跳过 AOT 处理需用 maven.test.skip=true，-DskipTests 不再生效 写入后续构建脚本约定

未决项（架构阶段）

  • 持久层：Spring Data JPA / MyBatis / jOOQ —— 未定
  • 数据库：PostgreSQL / MySQL —— 未定
  • 认证方案：Session / JWT / OAuth2 —— 未定
  • 是否使用 GraalVM Native Image：未定（Spring Boot 4 需 GraalVM 25+）
