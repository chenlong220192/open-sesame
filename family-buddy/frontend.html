职责

本项目有两个前端形态，需求差异很大：

形态 使用者 交互特征 尺寸
管理端 Web 家庭成员（电脑 / 手机浏览器） 强交互、频繁录入 响应式，≥360px
大屏 Dashboard 电视（遥控器 / 无交互） 只读展示、自动刷新、常驻 固定 16:9，1920×1080 为主

两者是否用同一个工程，尚未决策 —— 留到架构阶段，届时新增 ADR（见 ADR-0005）。

3 架构定稿（含前端工程划分） —

硬性约束

  1. 手机端浏览器可用（家人主要用手机，响应式是 P0 需求）。
  2. 大屏端只读，不得提供录入/编辑入口。
  3. 大屏端必须优雅降级：单卡片失败不影响其它卡片；断网不白屏。
  4. 前端隐藏菜单不构成权限控制，真正的校验在后端。
  5. 大屏端敏感卡片默认隐藏或脱敏。
