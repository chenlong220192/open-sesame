家庭伙伴 —— 面向多家庭的 SaaS 化家庭信息管理平台。前后端分离。

当前阶段：调研 / 需求分析（Requirements） 功能设计与架构设计尚未启动，backend/ 与 frontend/ 暂无业务代码。

一、项目定位（一句话）

把分散在微信群、备忘录、Excel、纸质单据、各 App 里的家庭信息，收敛到一个可长期沉淀、多成员协作、支持电视大屏展示的平台。

二、仓库结构

路径 用途 当前状态
docs/ 全部项目文档（需求 / 功能设计 / 架构 / API） 需求分析进行中
docs/01-requirements/ 需求分析文档集 进行中（本次产出）
docs/02-functional-design/ 功能设计文档 占位，未启动
docs/03-architecture/ 架构设计文档 占位，未启动

backend/ 后端服务工程 占位，未初始化
frontend/ 前端 Web 工程 占位，未初始化

单仓库多项目（monorepo）。前后端物理独立、可各自构建，共享文档与后续 CI。

三、技术基线

已确定项（细节待架构阶段）：

层 选型 备注
后端 Java 25 (LTS) + Spring Boot 4.1.x + Maven 版本现状见 ADR-0004
前端 Vue 3 + Vite + TypeScript 组件库/状态管理待定，见 ADR-0005
数据库 待定 架构阶段决策
部署 公有云服务器 SaaS 形态，见 ADR-0003
移动端 远期规划 本期不做任何设计

版本核实结论：Spring Boot 4.0.0 于 2025-11-20 GA，4.1.0 于 2026-06-10 GA（当前推荐用于新项目）；Spring Boot 4.0 最低 Java 17，一等公民支持 Java 25。来源：spring.io 官方博客，2026-10-01 查阅（实测）。 Spring Boot 4.2 预计 2026-11 发布（来源：InfoQ，文档级）。
